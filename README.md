## 📱 项目简介

腕上AI是一款专为智能手表设计的轻量级AI应用，集成了AI对话、AI绘画和AI翻译三大核心功能。无论你是想与AI助手聊天、快速生成插画，还是进行多语言翻译，腕上AI都能在手表上为你提供便捷的智能服务。

> ⚠️ **项目状态**：此仓库为本应用完整源码，项目已停止更新，仅供学习参考使用。

---

## ✨ 功能特性

### 🤖 AI对话
- 基于SparkApi的NovaMindAI智能对话
- 支持搜索、答疑、写作等多种任务
- 长按消息可一键复制内容

### 🎨 AI绘画
- 根据文字描述生成插画、设计图、场景图
- 生成图片支持长按保存至相册
- 实时反馈绘画进度

### 🌐 AI翻译
- 自动识别待翻译内容的所属语言
- 高准确度翻译为中文
- 长按翻译结果可复制

### ⚙️ 设置
- 模型切换支持
- 按钮点击音效开关
